# Designcraft's tools

One mastery guide per tool: getting the very best out of it, not just switching it on. The lead reads a guide before using the tool on a job.

A good guide covers:

- **What it's best at**, and where another tool beats it.
- **Setup:** what to install or sign up for, what it costs, and the one command that proves it works.
- **Getting the best out of it:** the settings, habits and tricks a master uses, with an example of the difference they make.
- **Where it goes wrong:** the common failures and how to spot each one early.
- **Safety:** what it uploads or spends, and when to ask Sean first.

When a better tool turns up, tell Sean what it would take to get it, and write its guide once he has it. An old restriction is a question for Sean, not a rule.

## The guides

Start with the tool list, which has the picks, the prices, the privacy notes and Sean's answers. Then one guide for each kind of work:

- **Finding and studying references:** the Awwwards and Mobbin guide. Award-winning sites and real app screens, how to search them well, and what their measuring tools miss.
- **The canvas Sean reacts to:** the Claude Design guide. The one Sean most wants to master.
- **Designing in real code:** the designing-in-code guide. Plain web code steered by the design skills, or Tailwind and shadcn/ui when Devcraft will build in React.
- **A design system:** the design values and Style Dictionary guide. One file of named values, turned into web code, and reading an existing brand.
- **Type:** the Fontsource and Fontshare guide. Self-hosted faces, licences, and loading without the page jumping.
- **Colour:** the OKLCH and Radix guide. Palettes, dark mode and measuring contrast.
- **Icons:** the Lucide and Iconify guide.
- **Spectacle on the web:** the Three.js, GSAP and Lenis guide. 3D, shaders, and motion tied to scroll.
- **Presentations, in Sean's order:** the Reveal guide and the HyperFrames slideshow guide for a spectacle, and the Claude Slides guide for a clear deck made fast.
- **Checking before Sean sees it:** the checking-a-design guide. Three checks, what each catches, and what all three miss.
- **Showing options side by side:** the Decide page guide.

Pictures and illustration are borrowed from Motioncraft, and their guides stay where they live.

The research behind the book list is here too.
