# Motioncraft's tools

One mastery guide per tool: how to get the very best out of it, not just how to switch it on. The lead reads a guide before using the tool on a job.

A good guide covers:

- **What it's best at**, and where another tool beats it.
- **Setup:** what to install or sign up for, what it costs, and the one command that proves it works.
- **Getting the best out of it:** the settings, habits and tricks a master uses, with an example of the difference they make.
- **Where it goes wrong:** the common failures and how to spot each one early.
- **Safety:** what it uploads or spends, and when to ask Sean first.

Tools are scouted, not inherited. When a better tool turns up, tell Sean what it would take to get it, and write its guide once he has it. An old restriction on a tool is a question for Sean, not a rule.
